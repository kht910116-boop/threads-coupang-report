# AutoTube Studio

유튜브 영상을 **대본부터 캡컷 프로젝트까지** 한 줄로 끌고 가는 개인용 로컬 도구.

**API 키를 하나도 안 써도 전 단계가 돈다.** 구독 요금제는 API 키를 주지 않지만,
구독 CLI와 구독 웹(백그라운드 브라우저)으로 같은 일을 한다.

```
1 대본 ─ 2 구조 ─ 3 음성 ─ 4 스토리보드 ─ 5 이미지 ─ 6 영상화 ─ 7 자막·효과 ─ 8 캡컷
                        매 단계에 비서 봇이 따라다닌다
```

## 설계의 축: 단위가 둘이다

```
자막 라인  = 대본 최소 단위 = TTS 한 덩어리 = 자막 한 줄
장면       = 연속된 라인 묶음 = 그림 한 장이 걸리는 단위
```

장면은 임의로 나누지 않는다. **라인들의 실제 음성 길이 합**이 파트별 '장면 간격'에
들어오도록 앱이 계산하고, 모델은 이미 정해진 장면에 그림만 붙인다. 그래야
훅 8\~13초 / 파트 12\~22초 같은 기준이 실제로 지켜진다.

## 시작하기

**받은 폴더에서 파일 하나를 더블클릭하면 됩니다.**

| 운영체제 | 실행할 파일 |
|---|---|
| Windows | `시작하기-Windows.bat` |
| macOS | `시작하기-Mac.command` |

Node.js 확인 → 필요한 파일 설치 → 서버 시작 → 브라우저 열기까지 한 번에 합니다.
처음 한 번만 1~3분 걸리고, 그다음부터는 몇 초입니다.
**뜬 검은 창은 닫지 마세요.** 그게 서버입니다. 끄려면 그 창에서 Ctrl+C(맥은 Control+C).

macOS에서 "실행할 수 없음"이 뜨면 터미널에서 한 번만:

```bash
chmod +x "시작하기-Mac.command"
```

### 직접 명령어로 켜기

```bash
npm install
npm run dev        # → http://localhost:3000
```

### 준비물

| | 없으면 |
|---|---|
| **Node.js 20 이상** | 앱이 안 뜬다. 런처가 받는 곳을 열어준다 |
| **Claude Code** (`claude` → `/login`) | 앱은 뜨지만 대본 생성이 안 된다 |
| **Chrome** | 앱은 뜨지만 구독 웹 자동화가 안 된다 |

## 8단계

| | 단계 | 하는 일 |
|---|---|---|
| 1 | 대본 | 주제 + **레퍼런스 링크 최대 5개**를 근거로 대본을 쓴다 |
| 2 | 구조 | 훅+인트로+행동유도-파트N-클로징. 라인 단위로 고친다 |
| 3 | 음성 | 서비스·세부모델·속도 + 앞/뒤/줄사이/파트사이 무음 |
| 4 | 스토리보드 | 간격 슬라이더 → 묶기 미리보기 → 생성. 파트별 탭 |
| 5 | 이미지 | 화풍 접두부+장면묘사+접미부로 그림체를 고정 |
| 6 | 영상화 | 장면별로 AI 영상 전환 |
| 7 | 자막·효과 | 폰트·위치·색 + 씬 효과 12종 |
| 8 | 캡컷 | 드래프트 + 범용 번들 |

라인을 고치면 그 줄의 음성이 지워지고 장면 길이가 다시 계산된다. 마음에 드는 장면은
**잠금**해두면 다시 만들어도 살아남는다.

## 구독으로 돌리는 법

### 대본·스토리보드·비서 — 구독 CLI

CLI마다 플래그가 다르므로 러너는 CLI 이름을 하나도 모른다.
`data/agents.json`(연결 상태 화면에서 편집)이 전부 결정한다.

```jsonc
{
  "id": "claude",
  "command": "claude",
  "args": ["-p", "--system-prompt", "{{system}}",
           "--json-schema", "{{schema}}",
           "--output-format", "json", "--tools", "", "--strict-mcp-config"],
  "promptVia": "stdin",      // stdin | arg
  "supportsSchema": true,    // false면 스키마를 시스템 프롬프트에 글로 넣는다
  "resultPath": "result"     // JSON 봉투 안 경로. 비우면 stdout 전체
}
```

자리표시자는 `{{system}}` `{{user}}` `{{schema}}` 셋뿐이고, 값이 비면 짝이 되는 앞
플래그까지 같이 빠진다. 스키마 플래그가 없는 CLI, 시스템 프롬프트 자리가 없는 CLI도
자동 처리된다.

기본 항목: `claude`(**검증 완료**), `codex`·`grok`·`antigravity`(플래그 미검증 초안).

### 대본·비서 — 구독 웹 (백그라운드 브라우저)

CLI가 없는 서비스는 브라우저로 돌린다. **작업 중 창이 뜨거나 포커스를 뺏지 않는다.**

- 프로바이더마다 **전용 프로파일**(`data/browser-profiles/<id>`). 평소 브라우저는 안 건드린다
- 실행은 **헤드리스**
- 창이 뜨는 건 **최초 1회 로그인할 때뿐**
- 같은 프로파일에서 **세션 쿠키를 꺼낼 수 있다**

완료 판정은 사이트별 '생성 완료' 표시를 찾지 않고 **답변이 일정 시간 안 변하면 끝**으로
본다. 사이트를 안 가리고 UI가 바뀌어도 안 깨진다. 선택자는 `data/web-providers.json`.

### 음성·이미지·영상 — 구독 웹에서 파일 받아오기

결과를 가져오는 방식이 사이트마다 둘로 갈려서 둘 다 지원한다.

| 방식 | 언제 | 어떻게 |
|---|---|---|
| `element` | 결과가 `<img>`/`<audio>`로 화면에 뜰 때 | src를 **페이지 안에서** fetch해 base64로 꺼낸다. `blob:`·`data:`도 되고 로그인 쿠키도 실린다 |
| `download` | 다운로드 버튼을 눌러야 할 때 | 버튼을 눌러 떨어지는 파일을 가로챈다 |

`data/web-media.json`(화면에서 편집):

```jsonc
{
  "id": "gemini-image",
  "kind": "image",                    // image | audio | video
  "url": "https://gemini.google.com/app",
  "promptSelector": "rich-textarea div[contenteditable='true']",
  "submit": "enter",
  "extract": "element",
  "resultSelector": "generated-image img",
  "settleMs": 2000                    // 저해상도 미리보기가 먼저 뜨는 사이트 대비
}
```

서비스 드롭다운에 `web:<레시피id>`로 함께 뜬다. **'시험' 버튼**으로 선택자가 맞는지
바로 확인할 수 있다.

### 직접 넣기 — 언제나 통하는 퇴로

어느 단계든 '직접 넣기'로 두면 앱이 프롬프트만 뽑아준다. 구독 웹에 붙여넣고 결과물을
업로드하면 나머지(타임라인·자막·캡컷)는 그대로 굴러간다.

### 우선순위

**CLI → 웹 → 종량제 API** 순으로 준비된 것을 쓴다. `PLANNER_AGENT=<id>`로 고정 가능.

> 구독에는 사용량 한도가 있다. 한 편에 2\~3분이라 하루 몇 편은 여유롭지만, 롱폼을 수십 편
> 몰아 돌리면 한도에 닿는다.
>
> 로그인된 웹 UI를 자동 조작하는 것은 대부분 서비스 약관의 금지 항목이다.
> 본인 계정·개인 용도라도 계정 제재 가능성은 남는다.

## 내보내기 결과

```
data/exports/<프로젝트>/<제목>/
  capcut/           캡컷 드래프트 (폴더째 캡컷 프로젝트 폴더로 복사)
  assets/           scene-001-img.png, line-001-aud.mp3 … 순서대로 번호
  subtitles.srt     무음까지 반영된 자막
  storyboard.csv    씬별 시각·길이·효과·한글요약·프롬프트 (엑셀에서 열린다)
  script.md         대본 + 장면 + 직접 걸 효과 목록
  project.json      원본 데이터
  README.txt        쓰는 법
```

`CAPCUT_DRAFT_DIR`을 설정하면 캡컷 프로젝트 폴더까지 자동 복사한다.

### 캡컷에 대해 알아둘 것

**드래프트 형식** — `draft_content.json`은 공개 문서가 없고 앱 버전마다 다르다. 여기
생성기는 최선의 추정이고 안 열릴 수 있다. 그래서 항상 범용 번들을 같이 낸다.
`assets/`를 번호 순으로 올리고 `subtitles.srt`를 얹으면 결과는 같다.

**효과** — 캡컷 전환·효과는 내부 라이브러리 id가 있어야 붙는다. 그래서 **키프레임으로
표현 가능한 것만** 실제로 건다:

| 걸린다 | 안 걸린다 (목록으로 안내) |
|---|---|
| 페이드·디졸브 → 투명도 | 블러 |
| 줌인·줌아웃 → 배율 | 글리치 |
| 좌우 팬 → 위치 | 오버레이 |
| 블랙/화이트 플래시 → 급변 | |

**자막 폰트** — 미리캔버스·캔바 폰트 이름을 그대로 넣으면 드래프트에 실리지만,
**그 폰트가 로컬에 설치돼 있어야** 캡컷이 렌더링한다.

## 확장하기

- **프리셋** — 화면에서 만든다. 코드 기본값은 `src/lib/presets/defaults.ts`
- **CLI** — `data/agents.json`에 항목 추가 (코드 수정 없음)
- **웹 서비스** — `data/web-providers.json`(챗) / `data/web-media.json`(파일)에 추가
- **API 어댑터** — `src/lib/providers/`에 구현체 추가 후 등록소 배열에 넣기

## 구조

```
src/lib/
  types.ts              전체 데이터 계약
  engine/
    prompt.ts             대본·스토리보드 프롬프트
    agents.ts             구독 CLI 레지스트리
    cli.ts / web.ts / api.ts   세 경로. 전부 complete() 하나만 구현한다
    index.ts              준비된 것을 우선순위대로 선택
  pipeline/
    grouping.ts           자막 라인 → 장면 묶기
    timeline.ts           무음까지 반영한 시각 계산 (SRT·캡컷·화면이 공유)
    audio.ts              WAV/MP3 길이 읽기 (ffmpeg 없이)
    generate.ts           대본·스토리보드 생성, 비서 컨텍스트
  providers/
    web/driver.ts         백그라운드 브라우저 (챗 + 파일)
    web/recipes.ts        챗 레시피
    web/media.ts          파일 레시피
    tts/ · image.ts · video.ts   등록소 (web: 접두어를 해석한다)
  export/
    capcut.ts             드래프트 생성
    bundle.ts             드래프트 + 범용 산출물
src/app/                UI + API 라우트
data/                   프로젝트·프리셋·레시피·에셋 (gitignore)
```
